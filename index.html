JS Задачи

1 – 8  /  vanilla js
01
Арифметика трёх чисел
Удвоить 1-е, уменьшить 2-е на 3, возвести 3-е в квадрат, затем найти сумму всех трёх.
02
Условное преобразование числа
[2–5] → +10  |  [7–40] → −100  |  ≤0 или >3000 → ×3  |  иначе → 0
03
Доллары → Рубли → Конфеты
Таблица из 100 строк: $1–$100 → рубли → кг конфет (1 кг = 20 руб.).
04
Шифрование цифр
Каждая цифра D кодируется буквой (A+D), повторённой (D+1) раз. Например: 0→A, 1→BB, 2→CCC.
05
Массив из N простых чисел
Заполнить массив первыми N различными простыми числами.
06
Максимум кратный 3 на нечётных индексах
Введите числа через пробел. Среди элементов с нечётными индексами (1,3,5…) найти максимум, кратный 3.
07
Матрица с единицами на побочной диагонали
Матрица N×N из случайных чисел [0–9], на побочной диагонали — единицы.
08
Триграммы: замена и сортировка
Разбить строку на фрагменты по 3 символа. Заменить средний символ случайным, не совпадающим ни с одним в фрагменте. Отсортировать по алфавиту.
